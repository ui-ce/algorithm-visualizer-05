## 🎯 هدف پروژه (Project Goals)

نسخه‌ی پایه‌ی این سامانه (پایان‌نامه‌ی کارشناسی پیشین، همین استاد راهنما) یک **معماری سه‌لایه‌ی مستقل از زبان نمایش** برای ثبت، قاب‌سازی و نمایش الگوریتم‌ها طراحی کرد، اما تمرکزش صرفاً روی بنیان معماری بود — بدون ورود دستی داده، بدون آموزش ساختاریافته و بدون هیچ سازوکار سنجش یادگیری.

هدف این پروژه، **حفظ کامل صحت معماری نسخه‌ی پایه** و افزودن یک لایه‌ی کامل از تجربه‌ی کاربری و تعامل آموزشی روی همان بستر است:

- ورود دستی داده، تولید تصادفی و الگوهای خاص (بهترین/بدترین حالت، تقریباً مرتب، معکوس)
- کنترل کامل اجرا: پخش، توقف، گام به جلو/عقب، تنظیم سرعت
- **هم‌گامی زنده‌ی شبه‌کد با اجرای بصری** — هایلایت خط جاری + توضیح کوتاه هر عملیات، هم‌زمان با مصورسازی
- مدل سه‌فازی **یادگیری / تمرین / آزمون** برای هر الگوریتم
- حالت **مقایسه‌ی مستقیم دو الگوریتم** روی یک داده‌ی مشترک
- سیستم آزمون سه‌سطحی (ساده/متوسط/دشوار) با سازوکار ستاره‌بندی
- پشتیبانی کامل دوزبانه (فارسی/انگلیسی) با چیدمان RTL/LTR، و تغییر پوسته‌ی روشن/تاریک

الگوریتم‌های پوشش‌داده‌شده: **Bubble Sort، Merge Sort، Binary Search، Dijkstra، DFS** به‌همراه ساختارهای داده‌ی **Stack** و **Queue**؛ Bubble Sort به‌عنوان پیاده‌سازی مرجع، مبنای تعمیم بقیه است.

## 🏗️ معماری کلی

پروژه به‌صورت یک **Monorepo** سازمان‌دهی شده و از سه ماژول مستقل تشکیل می‌شود که خروجی‌شان توسط برنامه‌های نمونه مصرف می‌شود:

```
Final Project/                      ← ریشه‌ی workspace
├─ modules/
│  ├─ recorder/                     ← typescript-recorder   (ثبت رخدادهای الگوریتم)
│  ├─ framer/                       ← typescript-framer      (تبدیل به دنباله‌ی قاب‌ها)
│  └─ renderer/                     ← typescript-angular-renderer (خروجی وب/لاتک)
│      → هرکدام به dist/ کامپایل می‌شوند
│
└─ examples/
   ├─ web-examples/                 ← ★ برنامه‌ی اصلی (Angular) — همین‌جا اجرا می‌شود
   └─ latex-examples/               ← نمونه‌های تولید خروجی PDF/LaTeX
```

سه لایه‌ی هسته‌ی معماری (بدون تغییر نسبت به نسخه‌ی پایه):

| لایه | مسئولیت |
|---|---|
| **Recorder** | ثبت رخدادهای الگوریتم (مقایسه، جابه‌جایی، …) در قالب دستور |
| **Framer** | تبدیل دستورهای ثبت‌شده به دنباله‌ای از قاب‌های کامل وضعیت |
| **Renderer** | تبدیل هر قاب به خروجی نهایی — نمایشگر وب (Angular) یا نمایشگر لاتک |

Backend: **Supabase** (احراز هویت + ذخیره‌ی نتایج آزمون). پیشرفت آزمون به‌صورت مهمان در `localStorage` نگه داشته می‌شود.

> جزئیات کامل معماری، نیازمندی‌ها و تصمیم‌های طراحی در گزارش پروژه‌ی پایانی (فصل سوم) آمده است.

## 🚀 نصب و راه‌اندازی سریع (Quick Start)

برنامه‌ی اصلی که باید اجرا شود **`examples/web-examples`** است. پیش‌نیاز: Node.js و npm نصب باشند.

### ۱) کامپایل ماژول‌های هسته

هر یک از سه ماژول باید یک‌بار build شوند تا `dist/` تولید شود (به ترتیب Recorder → Framer → Renderer، چون هرکدام به قبلی وابسته است):

```bash
cd modules/recorder && npm install && npm run build
cd ../framer && npm install && npm run build
cd ../renderer && npm install && npm run build
```

> اگر بعد از تغییر در یکی از ماژول‌ها، تغییرات در برنامه‌ی وب دیده نشد، `npm run build` را در همان ماژول دوباره اجرا کنید و کش Angular را پاک کنید (پایین‌تر توضیح داده شده).

### ۲) اجرای برنامه‌ی وب (Angular)

```bash
cd examples/web-examples
npm install
ng serve
```

سپس به آدرس زیر بروید:

```
http://localhost:4200
```

راهنمای کامل‌تر این بخش (شامل جزئیات build نمایشگر) در `examples/web-examples/README.md` آمده است.

### ۳) (اختیاری) اجرای نمونه‌های خروجی LaTeX/PDF

برای تولید خروجی PDF از اجرای واقعی یک الگوریتم (مستقل از برنامه‌ی وب):

```bash
cd examples/latex-examples
npm install
cd src
npx ts-node a-star.ts   # یا هر فایل نمونه‌ی دیگر در همین پوشه
```

خروجی در `examples/latex-examples/src/output/<نام-الگوریتم>/` (شامل `.tex` و `.pdf`) قرار می‌گیرد. پیش‌نیاز اضافه: LaTeX نصب‌شده و دستور `pdflatex` در دسترس سراسری. جزئیات کامل در `examples/latex-examples/README.md`.

## 🩹 مشکلات رایج (Troubleshooting)

- **تغییرات دیده نمی‌شود بعد از build یک ماژول:** پوشه‌ی `examples/web-examples/.angular/cache` را پاک کنید و `ng serve` را دوباره اجرا کنید.
- **آیکون‌های Solar نصب نمی‌شوند:** پکیج `@solar-icons/angular` باید داخل `web-examples/` نصب شود، نه در ریشه‌ی workspace.
- **خروجی PDF گرفته نمی‌شود:** مطمئن شوید `pdflatex` به‌صورت سراسری در سیستم در دسترس است (`pdflatex --version`).
